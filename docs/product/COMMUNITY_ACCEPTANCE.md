## Owner-approved specification amendment (P0-T39)
This additive record updates the context of original specification sections 1, 3.2, 4.1, 4.2, 7.5, 9 and 13 without modifying immutable supplied documents. SSC remains optional; current menu-proof rule remains in force until documented moderator approval. Manual recording fallback remains available; proposed automatic-only recordings do not establish eligibility. No rule change is implemented by this amendment. The proposed SSC competitive proof path MUST identify actual engine-loaded track and difficulty, not selection intent or manually entered text. Record stable IDs and localized labels separately, per attempt/leg, tied to engine build, adapter, run/session/leg IDs, lifecycle sequence and timebase. Validate the mapping on every supported track/difficulty; unknown, training/practice, stale, changed, unsupported and contradictory identities remain explicit. Do not substitute UI selection, asset existence or manifest values for a verified loaded-track observation.

Overlay MUST display legible actual track/difficulty in recorded pixels from pre-start through official result, including restart transitions and each All Tracks/Championship leg; an in-game-only overlay is insufficient. Unknown identity must be visibly unknown, never stale/guessed. The overlay consumes a bounded immutable read projection, no engine pointers or synchronous encoder work. Capture/export bind observation, video interval and official result to the same attempt; retain original footage, coverage and gaps. Cross-check actual identity against declared submission category, per-leg metadata, independently inspected visible label and native race/replay file when available and supported. Optional replay remains optional under existing rules. Missing, unsupported or inconsistent evidence requires transparent review or incomplete coverage, not an automatic cheating accusation. A matching claimed label or client-side checksum is not authenticity or proof of no cheating.

## Moderator validator acceptance
Recompute independent checks from bounded untrusted input; show each source, identity, attempt/leg and timing coverage with evidence references. Distinguish inconsistent claims, insufficient evidence, unsupported native format and confirmed violations under an approved profile. Never trust claimed eligibility or derive local provenance from a package. Keep policy eligibility separate from integrity/capture/attempt status. Existing schema 2 remains caller-supplied/unverified. The T39 pure track_claims model is only a typed claim agreement primitive, not this validator or a production proof mechanism. It deliberately does not change submission review.
