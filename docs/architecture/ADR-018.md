# ADR-018 — Synthetic append-only journal and measured extended capture fixture
Accepted for isolated P0 experiments only; no game, local-origin or release approval.

Prefer immutable per-phase snapshots over replacing a mutable journal. Canonical bounded ASCII schema 1, exact synthetic origin, sequence reconstructed through existing pure model; explicit run ID and trusted existing private single-writer directory. Stage with exclusive create, flush/fsync file, verify exact bytes, publish same-directory no-replace hardlink. No overwrite, auto scan, destructive repair or migration. Retry exact valid pending or same-file alias; invalid/conflicting facts require review. Process death tested at three explicit points, not power-loss, directory metadata durability, adversarial paths or concurrent writers. No native index or archive verifier connection, no local/PB authorization. Separate store can be removed with one Python test target.

Extend existing isolated WGC/MF fixture to 1200 selected frames (1440/90s bounds, 80s acquisition deadline), preserve 60/240/600 fixtures. Same queue and timing policies. Measure selected processing latency nearest-rank median/p95/p99/max, total fixture wall, own-process kernel+user CPU, encoder drain; no gameplay benchmark or threshold. New C++ pure summary test independent from Windows API. Local model/store/summary tests verified, candidate Windows NOT_RUN at preparation; actual audio and device recovery not claimed. G1 unchanged. Roll back by retaining v0.0.18-p0 main until candidate CI and scope review.
