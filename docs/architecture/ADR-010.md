# ADR-010 — Independent offline foundations while G1 is blocked

Accepted for offline development only, 2026-11-26. Governing protocol permits isolated unit-test work with blocked runtime gates. Keep QPC adapter behind existing IClock and use integer elapsed conversion, raw samples retained; no event hookups. Implement reference storage/evidence/API preview using Python 3.10+ standard library and SQLite; no shipped production Python/SQLite runtime decision. Alternatives: wait for loader validation (unnecessary for pure computations), choose production storage/codec now (premature), expand native mocks (not useful for these tasks). Explicit caller-owned paths, no game writes, no external network, no release authorization. Future C++ storage adapter and schema require review and migration, no forced database choice. Keep modules/test targets removable. G1/G2/G3/G4 and approval gates unchanged; test target count rises from nine to thirteen. Roll back by reverting T16 source/tests, preserving references and user data. No new third-party dependencies distributed.
