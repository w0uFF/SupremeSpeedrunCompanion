# ADR-012 — Bounded worker, run manifest and no-replace publication

Accepted for independent P0 development only, 2026-11-26. Separate queue/sink lifecycle from existing capture ownership ledger. Prefer bounded FIFO with explicit full/invalid counters over blocking producer until encoding completes; short mutex and allocation remain, so no frame-hook latency promise. Sink cancellation is cooperative. Preserve exact caller timestamps, not inferred race timing. Add source-level run repository port, no production DB selection. Extend experimental stored archive with opt-in schema 2 metadata, preserve schema 1. Publish verified partial using same-directory hard link, fail closed where unsupported, rather than replace any destination. Recovery explicit, no crash durability claim. No new external dependencies, no native admission or release authorization. Revert isolated new tools/ports and tests if necessary; existing schema 2 evidence may require a compatible reader, retain files. No game modifications.
