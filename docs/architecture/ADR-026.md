# ADR-026 — Fixture resource isolation and injected finalization failure

Status: accepted for isolated P0 fixtures; runtime validation pending.

## Context
T35 observed handles 337→339→341 after same-process scopes, unchanged over short settling. No individual handle attribution exists. Successful WriteSample is not successful finalization.

## Decision
Five independent child processes, three same-process scopes per mode: window only; D3D11 device/DXGI/WinRT wrapper; WGC window/item/device/pool/session setup without StartCapture; MF Worker idle begin/cancel; MF Worker synthetic 60-frame write/finalize. Four resource samples per scope (before, after destruction, +1s, +3s): 15 scopes / 60 samples, 180 independently decoded 160x96 synthetic frames. Require exact marker order, stable PID within each child, peak/working/private bounds, valid handles/GDI/USER, exact artifact presence/size and worker outcomes; no owner attribution or leak threshold. Compound WGC mode is not individual pool attribution. Separate PIDs isolate process histories, not OS global caches.
Actual own-window HD same-process sequence 600 success / 120 injected sink-finalize-failure / 600 success. Default-disabled fixture sink throws before calling real MF Finalize, after all writes; it does not simulate an actual MF HRESULT or prove physical-device recovery. Expected failure: 120 selected/accepted/written, 0 discarded/unoffered/drops/invalid, high-water 1..8, failed worker after join, incomplete artifact (never successful/finalized evidence), subsequent successful recording. Independently decode 1200 successful frames at 1280x720, require previous timestamp/pattern/queue/display-restoration gates, 30 stage samples and four GUI checkpoints. Existing write-failure and cancellation contracts unchanged; production Worker API untouched.
Fresh separate child after actual published-journal partial_write interruption independently asserts plan None, observe review, Store.inspect ReviewRequired. Parent requires fresh-child success marker and exit 0, verifies exact prior/torn journal, finalized ZIP and unchanged DB bytes again, and native index missing; existing stale reconciliation and interruption regressions preserved. No power-loss or competing-writer guarantee.
Use shared fixture helpers and existing Worker instead of a production API change. Preserve current optional mod, G1, audio and provenance restrictions. Raise only capture job timeout for added workload. No threshold based on one host or claim of physical MF failure.

## Alternatives rejected
Global handle enumeration (unnecessary attribution/privacy risk); treating an MP4 artifact as finalization success; disabling existing capture regressions; treating shared finish slot as human completion.
