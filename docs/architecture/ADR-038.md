## Decision
Use existing B-owned overlay as a decorator of the already validated media backend rather than modify native rendering or duplicate clocks and game schemas. Preserve existing worker/encoder composition and tests; no overlay on fixture capture by default. Separately gate persistent output and history rather than bundle unrelated features. Capture-owner producer responsibility includes validated identity, reliable event order and shared timestamp epoch; supplied snapshot origin is not authority. Failure must remain incomplete and not affect gameplay. Rollback removes six additions, two test registrations and version/docs updates. No installed/native or persisted effect. Actual Windows compile and complete original integrated backend test plus identity test required; no claim from source review alone.
