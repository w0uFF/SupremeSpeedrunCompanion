# ADR-017 — Extended bounded capture and synthetic private journal model

Accepted for isolated P0 research only; no runtime or release approval.

Keep the one-frame lookahead, bounded Worker, test-only encoder and independent decode. Extend fixture limits to 720 frames/45 seconds, actual test to 600 frames, retain 60/240 regressions, nominal terminal and capped assigned hold. Inject device removal explicitly; cancellation is not finalization. Preserve actual endpoint audio blocker; do not infer actual device recovery, gameplay capture or performance.

Use immutable pure synthetic Context/Journal states for terminal, verified, published and indexed. Bind run ID, generation, settings, terminal, capture completeness and exact digest. No file codec, native connection, actual authority, local/PB or imported promotion. Unknown/missing/conflicting facts preserve for review; verified final plus identical row with stale phase requests reconciliation only. No automatic repair or durability promise.
