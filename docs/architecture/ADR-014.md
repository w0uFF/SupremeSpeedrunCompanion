# ADR-014 — Native derived run index and redacted settings binding

Status ACCEPTED for independent P0 development, 2026-11-26. No game runtime or release approval.

Context: prior Repository port, Python SQLite reference, WinSQLite system ABI probe, native immutable AttemptSettings, experimental schema-2 archive. Need persistence and per-attempt evidence without extra runtime dependencies or mixing player preferences with competition policy.

Decision: use the tested system WinSQLite API from a narrow shared infrastructure header, native QueryRepository port extension and separate versioned private runs.sqlite. Keep record insert-only, annotation mutable, PB explicit, stable digest comparison, bounded queries and owner-thread off-game I/O. Exact schema/app ID; reject unknown versions and unexpected objects. Do not automatically migrate Python prototype or open arbitrary imported SQLite. No DB treated as authoritative archive. Preserve originals; future derived-index migrations create reviewed new representation. Alternative bundled SQLite dependency deferred, text-only flat index rejected for transactional queries. Existing profile JSON store remains independent.

Bind immutable settings via optional canonical diagnostic member in existing schema 2 rather than a breaking manifest schema bump. Redact private profile name and destination, check identity and digest independently. No claims of actual recording settings, eligibility, authenticity or policy approval. Rehashed coherent tampering still possible. No live producer/indexer integration.

Consequences: system ABI/availability is Windows-dependent, explicit private path and single owner, no crash guarantee or hostile path defense. New index schema has no migration/retention/recovery protocol; actual archive admission pending. Older schema-2 reader does not check new semantic member; optional absent remains valid. Rollback source by reverting isolated new adapter/port and tests; preserve databases and archive bytes. Evidence: Windows run 45803303956, final 33/33 both configurations, independent SQLite and archive fixture tests. G1 remains blocked.
