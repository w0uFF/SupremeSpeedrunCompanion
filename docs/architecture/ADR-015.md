# ADR-015 — Verified nonlocal archive index and timestamped capture handoff

Accepted for independent P0 work, 2026-11-26. No real-game or release approval.

Archive admission: extend existing verifier with opt-in manifest return from its validation pass, reuse existing no-replace publisher and native Repository. Managed pending/final ZIP is durable source of retry; separate native index derived from exact verified manifest hash. Prefer explicit manual retry to unreviewed directory scanning or cross-filesystem transaction promises. Imported provenance comes from ingestion context, never archive claims; synthetic explicit and no local admission. Use an unclassified comparison namespace until approved competition identity is available, no invented profile digest. Keep schema unchanged; actual local attempt producer, automatic recovery/status view and migration deferred. All bytes preserved except own incomplete copy on error and publisher's exact pending hardlink alias. Trusted quiescent directory, no power-loss guarantee, no authority claim.

Capture: bounded private WGC timestamped sequence (SSCTIME1) to existing Worker/AsyncSink video-only mode, use actual absolute 100ns timestamps normalized to first selected frame, duration from next frame capped at 100ms, last nominal 40ms. Compare decoded timestamps against original timeline with explicit exploratory 2ms tolerance; log actual difference. No synthetic audio, no attempt alignment; hold cap does not establish actual coverage. Staged sequence chosen to verify clock preservation before concurrent producer/sink plumbing. Source fixture not public archive format; bounded 24 frames/8s, no extra dependency. Next concurrent lookahead producer with explicit drops, resize/device-loss and live coverage. Revert isolated changes if needed; preserve archives and index. Actual tests run 45816213715; G1 blocked.

T26 follow-up ADR-016 extends staged fixture to bounded concurrent capture and explicit single-run read-only status. Nonlocal admission and preservation policy unchanged.
