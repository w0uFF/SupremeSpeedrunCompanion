# ADR-008 — Read-only native research and replay position probe

Accepted for offline diagnostics only, 2026-11-26. Preserve existing C++ contracts and synthetic C ABI. Two independent Python tools inspect trusted local PE/replay files, isolated from bootstrap and engine admission. Prefer static candidate reports and null markers over speculative offsets or geometry classification. Keep private reference binaries, upstream source and raw disassembly outside public repository. GNU objdump is optional local research tooling, not a shipped dependency; synthetic tests require only standard Python. Terminal replay record is excluded from coordinate bounds until its meaning is confirmed; not a validity or authenticity test. No copied upstream implementation, no new runtime dependency, no native capability. GPL integration obligations and license pending. Rollback by reverting the research tool/test changes; existing game and loader untouched.
