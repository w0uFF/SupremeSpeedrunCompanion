## Decision and alternatives
Group B-REC-02, 02b and 02c because reusable MF writer depends on owned-video-sink interface and backend uses extended policy. Keeping separate MF implementation duplicates existing codec lifecycle; bundling overlay/persistence expands review surface. Preserve original fixture behavior via facade and default timeline policy; opt-in extended policy remains uncalibrated. Appended tests use existing contracts/Threads targets and strict warnings, no shared ABI or workflow edits. Actual Windows compilation and full applicable regressions required, no inference from Linux fakes. B retains implementation ownership; A integrates exact blobs only.
