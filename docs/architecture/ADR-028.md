# ADR-028 — Separate WGC support query, factory and item lifetimes

Status: accepted for isolated P0 fixtures; native validation pending.

Context: T37 repeated support query alone showed +1 settled handles per cycle, item setup +2, and pool/session added no further recurring increment. T36/T37 full HD lifecycles repeatedly showed337/339/341. These measurements are descriptive.

Decision: compare separate children with one support query before samples, no-op control, factory-only, item with recreated or persistent own window, and full setup. Require exact successful call counts plus prior resource evidence and no capture. Keep original repeated-query baselines. No production caching decision before evidence; persistent window baseline excludes creation and teardown. Add narrow startup-state and recovery refusal regressions; retain API and existing gates. Alternative rejected: speculative handle ownership, global enumeration, production caching or resource workaround before evidence. Rollback: remove candidate-only fixture and test additions; restore T37.
