# ADR-011 — Isolated media probe and constrained evidence archive

Accepted for offline development only, 2026-11-26. Use Windows SDK Media Foundation through a standalone opt-in probe and a separate read-only CI job, not a game module. Actual codec support requires execution; CI failure must be visible and distinguishable from core build failures. Use stored flat ZIP and bounded classic central directory for initial evidence prototype; avoid extraction and compression, limit payload to 1 GiB until large-file policy/recovery review. Exclusive output prevents overwrite. Self-contained manifest hash is consistency, not authenticity. Use existing Availability with a narrow injected C++ preferences store rather than choose a production database. No copied upstream implementation or new third-party dependencies distributed. No release authorization, G1/G4 or native capability change. Rollback by reverting isolated tools/tests and CI job; never delete existing user archives or databases.
