# ADR-013 — Explicit stream quality and QPC mapping
Accepted offline, 2026-11-26. Extend existing worker with per-stream counters without replacing aggregate API; measure handed-off time intervals, not video validity. Keep unknown coverage distinct from zero. Convert raw QPC ticks relative to explicit epoch with integer arithmetic; do not infer race timing. No native hooks, policy changes or dependencies. Rollback by reverting isolated worker/test changes.
