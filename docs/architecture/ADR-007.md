# ADR-007 — Hosted Windows CI and independent distribution

Status: accepted build infrastructure; public binary release conditional. Context: owner approved official GitHub-hosted Windows runners, per-main-commit releases without Actions artifacts, and possible optional upstream launcher integration. Use existing CMake targets and x86 Win32 builds, no self-hosted runner needed. Test Debug and Release. Keep publication separate from PR validation, gate on license and owner approval. Only diagnostic assets during P0. Use full-commit tag, SHA-256 and machine-readable manifest. Preserve previous snapshots. Stable releases need G6 and native runtime validation. Exact hosted image can change; record actual compiler and build results. No changes to engine ABI, competition rules or source snapshot.
