# ADR-019 — Synthetic recovery coordination and representative encoder measurement
Accepted for isolated P0 experiments only; no production or release approval.

Compose existing immutable synthetic Store and read-only archive_status with injected native compare/presence port. Match run ID, synthetic origin, exact manifest digest and terminal status; complete fixture capture requires finalized metadata, but finalized metadata alone does not imply coverage. Settings/generation remain private fixture facts bound at verification, not independently recovered from archive metadata. Reconcile only one next journal snapshot after re-inspection; no archive/index write, automatic cleanup, scan, local admission or PB. Missing/conflict/invalid/unknown state fails closed. Exact staged published/indexed retry allowed only when independently observed facts support it. Explicit archive/index operations remain outside coordinator; real process-death integration fixture kills child after publication and after index insertion. Single trusted owner, no cross-file atomicity/power-loss/hostile-path guarantee.

Keep existing low-resolution WGC and synthetic AV tests. Extend existing test-only MF sink using fixed low/720p specs, paced 250-frame 25fps moving checker bands at target 5Mb/s; bounded eight-slot NV12 payload queue, independent decode PTS and luma; record CPU/wall, producer generation+offer latency, drain, peak/current working set, current private commit and output bytes. File cap checked after finalization; subprocess timeout. Not a full memory/disk quota or actual gameplay/GPU measurement. No new runtime dependency. Local pure coordinator passed; native and HD candidate CI pending. Rollback retain v0.0.19-p0 main.
