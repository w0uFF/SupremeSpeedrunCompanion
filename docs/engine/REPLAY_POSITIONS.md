CLI: python tools/replay_samples.py <trusted local replay file>. Public Python function summarize(data) returns schema 1 with existing nested header, candidate sample period, unknown coordinate units, counts, finite XYZ bounds or null, and header-indexed candidate start/CP1/finish coordinates or null. Nonfinite coordinates are counted and omitted; no Infinity/NaN JSON emitted. Bounded read 8 MiB, existing structural and timing order checks; unsupported data raises ValueError, not an eligibility verdict. No name, file path, raw coordinates series, physical speed, RTA, official timing or game mutation emitted.

Need actual game-displayed times and confirmed geometry/coordinate units before any comparison or adjudication. Source and raw replay bytes not redistributed.

Dependencies: Python standard library and local replay_header.py only. CLI and pure function tested by tests/test_native_research.py; no feature module or bootstrap depends on it.
