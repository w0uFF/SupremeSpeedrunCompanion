# Experimental run manifest schema 2 and archive publication

The flat manifest.json adds all minimum fields named in project specification §9, with explicit null values for unknown optional metadata. This is a provisional offline schema, not final submission or a migration of existing files. run_manifest.build accepts caller-provided identity/status, 32-hex run/session IDs, canonical UTC seconds, build name, optional 64-hex game fingerprint and bounded text, IGT integer milliseconds/RTA integer nanoseconds (<2^63); RTA requires caller clock and event semantics. Unknown differs from zero. Unfinished attempts cannot claim final IGT. Finalized capture needs nonempty video member, not verified playback. replay_available means a replay role is present, not that replay can play. Coverage null, integrity not_assessed, policy_eligibility unknown, timing_provenance caller_supplied_unverified and mandatory warning. No verified times, game identity, evidence authenticity or eligibility implied. Caller must redact personal information; no credential/account fields. Canonical serialization sorted JSON keys, compact separators, ASCII escapes as Python json.dumps default; SHA-256 of exact manifest returned by independent verifier, not self-referential. Existing schema 1 remains accepted/created by default. Schema 2 optional metadata parameter to evidence_archive.create; existing payload member/hash checks run before metadata validation. Unknown versions fail closed. No extraction.

archive_publish.create_run creates exclusive .zip.partial outside trusted staging via existing archive writer, verifies, flushes file using fsync and uses os.link in same directory to publish atomically without replacing destination on supporting filesystems. Recovery: call publish(final,evidence_archive.verify) for a closed partial. Verify before publication. If final exists and refers to same file, verify again and remove partial alias; conflicting file remains untouched and partial retained. No link support means fail closed, preserve partial for manual recovery; never fallback to overwrite. Invalid partial remains for inspection, not automatically deleted. On create failure old writer removes own detected partial; interruption can leave incomplete file. No directory fsync, power-loss durability guarantee, protection against competing writers, hardlink/path races or hostile local filesystem; operate in owner-controlled quiescent staging/output directories only. Do not edit partial after publication if alias remains. No auto-recovery scan, import registration or gameplay access. Limits inherited from schema 1 (1 GiB stored ZIP, 64 members plus manifest), not policy limits.
