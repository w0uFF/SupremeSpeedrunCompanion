## Identity/provenance
Only verified schema-2 archives with known finished/restarted/abandoned/failed attempt status admitted. Schema 1 or unknown status rejected for indexing without changing source. Verified bytes/metadata consistency is not authenticity, gameplay, completeness or eligibility. Every ordinary import is indexed Origin::imported, including archives claiming local or synthetic. Explicit synthetic-fixture mode requires archive-declared synthetic origin and is never PB eligible. The native bridge refuses local origin on stdin; actual local producer/admission remains pending game/session validation. Repository remains a trusted internal port, not anti-tamper. Archive-declared origin preserved verbatim in source and managed ZIP. No origin upgrade or overwrite. Same run ID + all identical indexed fields yields identical; conflicting values/origin/digest yields conflict. Existing local PB query excludes imported/synthetic. No profile mapping from free-text profile_id or category guess: category unclassified, profile field uses reserved SHA-256 of ASCII SSC:unclassified-index-v1 (comparison namespace only, explicitly NOT an approved competition-profile hash). Event semantics accepted as bounded ASCII nonspace key else unknown; timing values are caller-supplied unverified manifest values. Raw original metadata stays in ZIP. No use of imported values as official PBs.

## Publication/recovery
Caller owns an existing trusted private archive directory; one owner, no concurrent writers. Managed name <imported|synthetic>-<32hex run_id>.zip; pending = same name + .partial. Verify source first, copy to exclusive pending bounded by existing physical ZIP limit (1GiB+manifest+chunk), flush/fsync, independently verify pending digest/identity before no-replace same-directory hardlink publish. Then verify final again and index. Preserve source and finalized archive on index failure. Retry using original, managed pending or finalized path with same origin. Existing valid final same manifest digest deduplicates (not necessarily identical ZIP container bytes); different manifest rejected without overwriting. Existing separate pending while final exists requires review; exact same-file hardlink alias recovery uses existing publisher. Existing corrupt/other partial preserved, no auto-delete; only incomplete copy owned by current call removed on copy exception. Crash during copy may leave invalid partial; explicit review/recovery required. Index conflict may leave additional verified archive in different origin namespace unindexed, retained for review. No directory scan, automatic cleanup, filesystem/DB atomic transaction, crash/power-loss or TOCTOU guarantee. Directory must be trusted and quiescent; do not use arbitrary untrusted directory structure. Existing DB requires explicit initialization; no open/create on missing insert. Native bridge accepts exactly 9 newline-terminated ASCII fields, max 128 chars per field, no trailing content, validated Record and nullable unsigned elapsed in signed-63 range. No local origin. This bridge does not independently parse archive, so invoke via trusted controller; direct invocation does not establish archive verification.
