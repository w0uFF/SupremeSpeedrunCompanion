# Offline evidence file inventory — schema 1

tools/evidence_inventory.py: inventory(root, selected), trusted closed staging directory, explicit mapping of simple portable ASCII filenames to video/replay/telemetry/timing/diagnostic roles. Returns sorted files list (path, byte size, lowercase SHA-256, role). No recursive scanning, symlinks/reparse points, traversal, reserved Windows device names, reserved manifest/checksum names or case collisions. Bounds: at most 64 files and 16 GiB each; stream in 1 MiB chunks. Checks size, inode and mtime before/after; not a security sandbox, cannot rule out every concurrent modification/hardlink/ancestor redirect. Caller must ensure closed, trusted staging and run off game thread. No file writes, media decode, archive extraction, ZIP generation, signature, authenticity or eligibility claims. Report always complete_package=false, eligibility_verified=false.

Python standard library plus existing baseline_snapshot.linked helper. No C++ bootstrap dependency, state or workers. Not the required full manifest schema; next step independent archive staging/verification and immutable manifest with provenance. Golden SHA-256 fixture for abc; negative cases for unsafe names, missing files, collisions, role, bound and links. Windows symlink test can skip if unavailable.
