# Synthetic-only append-only journal store (P0-T28 candidate)

No production authorization. Store(directory, run_id) accepts an explicit 32-character lowercase hexadecimal synthetic run ID and existing trusted private directory (no symlink/reparse directory at final component). Five immutable canonical ASCII JSON schema-1 snapshots, at most 1024 bytes each, name synthetic-<run_id>-<0..4>-<phase>.json, phases recording, terminal, verified, published, indexed. Same suffix .partial used for exclusive staging. JSON exact keys schema=1, origin=synthetic, run_id, generation, settings, phase, terminal, digest, capture_complete. Canonical sorted compact ASCII + newline; byte equality on decoding rejects duplicate keys, whitespace alternatives, wrong schema/origin, extra keys and inconsistent model state. A private fixture fact is not a trusted local attempt.

Read-only inspect uses only ten fixed paths; rejects nonregular/reparse files, mismatched identity/phase, broken predecessor chain, conflicting or separate pending and later phases after pending. Reconstruct successor using the pure T27 model, not metadata alone. Returns latest and exact pending, plus same-file alias flag. Invalid state raises ReviewRequired; storage exceptions propagate. No directory scan or automatic mutation.

Explicit append checks identity and full chain. Exact latest retry returns identical; different pending or skipped/changed transition refused. Write exclusive partial, flush/fsync, verify exact pending, fsync again, no-replace same-directory hardlink publish, remove own partial. If interrupted after link, exact same-file alias can be explicitly cleaned by retrying the same desired snapshot. Separate pending copies, corrupt partial and conflicting destinations are preserved. No filesystem/DB transaction, no directory metadata fsync, power-loss proof, hostile-path/TOCTOU or concurrent-writer defense. Single trusted owner only, hardlink filesystem required. Five final plus at most one expected pending in valid state; no automatic cleanup/retention. No archive verifier, native repository, PB or local authority.

Local verified tests: Python 3.13.5 Linux x86_64 six tests; real subprocess os._exit(91) after partial write, after flush/fsync, and after hardlink publication; valid retries and invalid preservation; canonical parser, wrong ID, missing predecessor, no-replace destination conflict, capture completeness.
