# Recording quality v1 (P0-T19)
Worker quality() returns a snapshot in fixed video/audio order; per stream accepted, written packet count, first and last-exclusive timestamp, sum of handed-off durations, internal gap, queue-full drops/duration, invalid and discarded counts. Unknown stream invalid events count only in aggregate. All timestamps are unsigned 100 ns units in a caller-established common origin. A stream with no written packets has unknown internal gap. Internal gap excludes pre-first/post-last intervals; handoff is not decoded content, signal, black-frame, coverage of race boundaries, or eligibility. Dropped durations cannot be interpreted as physical frames if producer packet granularity is variable. No retiming. high_water() reports maximum occupied queue slots, excluding in-flight packet. Snapshots separately locked; inspect after join for a consistent terminal report. qpc_to_100ns uses exact quotient/remainder truncation, rejects pre-origin, zero/unsupported frequency (>1 GHz) and overflow. No source clock correlation or gameplay boundary is inferred. No new native capability. Tests: test_recording_quality.cpp and expanded worker tests.
