# Baseline snapshot diagnostic schema 1

Purpose: support human Windows baseline checks with bounded read-only fingerprints of fixed files. Not an engine adapter, installed-disabled test, full installation inventory, eligibility check, or verified timing source.

Public CLI: python tools/baseline_snapshot.py snapshot <closed disposable game root>; python tools/baseline_snapshot.py compare <before.json> <after.json>. Both output JSON to stdout; the user decides where to save reports. Dependencies: Python standard library only. No engine capabilities, state, background workers, network or file writes. Run only on a trusted quiescent copy; not an adversarial filesystem sandbox. Root and explicitly walked components are checked for symlinks/reparse points, but ancestors outside the specified root and races with concurrent changes are not a security guarantee.

Snapshot schema=1, scope=closed_game_fixed_files, files map: six core filenames and twelve Saved_Data paths (defaults, control config, keyboard bindings, nine high times). Entries: present (byte size and lowercase SHA-256), missing, unsupported_link, unsupported_type, too_large, changed_during_read, unreadable. Maximum 64 MiB per file, 64 KiB report input; fixed names only, no recursive traversal, no raw save bytes, names from score rows, absolute paths or device IDs exported. Metadata comparison detects some concurrent mutation, not every possible race; game must be closed. Report schema/file set and per-entry values checked before comparison. Unknown statuses or schema rejected.

Comparison changes: unchanged, changed, absent_both, created, removed, unknown. core_observation=changed if any definite core change, unchanged if all six core files present with matching fingerprints, otherwise incomplete. These are file observations, not compatibility verdicts. Redirected saves can appear missing. runtime_verified and loader_gate_passed always false. A comparison cannot replace user observations or exact preflight profile matching. Use docs/testing/WINDOWS_BASELINE.md.

Tests: tests/test_baseline_snapshot.py; synthetic temporary files; real reference/staged files only inspected locally. Windows symlink test skips if the platform denies creation. Schema changes require explicit versioning and fixtures. Removing this tool/test target does not affect the companion or existing contracts.
