# Capture primitives — P0-T20
Portable C++17, no platform or engine dependency. bgra_to_nv12 accepts explicit byte length, stride, even dimensions 1..4096; conservative full stride extent required. BGRA alpha ignored. BT.601 limited-range integer coefficients and 2x2 chroma averaging; caller supplies correct color-space contract. Output tightly packed Y then interleaved UV. No resizing, gamma/HDR, color-profile negotiation or performance claims. Reject invalid layout. AudioObservation observes source device positions in sample frames; records total packets/frames, silent frames, discontinuity/timestamp-error flags, positive position gaps and regressions. Timestamp error resets expected position, avoids inventing missing intervals. Overlapping positions are reported, not corrected. Not a timebase conversion, silence detection, actual game coverage or eligibility. Both helpers owner-thread and removable. Tests use synthetic reference values. No runtime binding.
