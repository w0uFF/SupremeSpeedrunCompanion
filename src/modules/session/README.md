# session — prototype v1
Purpose: Synthetic race/session state and splits; no timer acquisition, native commands or official scoring.

Public surface: `public/session.hpp: Session, consume, snapshot, attempts`. Required dependencies: categories public catalog. Optional dependencies: none in P0. Owned state/config/files: bounded 128 attempts; per-session ID and monotonically increasing event sequence and attempt IDs; no config namespace or migration yet. Single caller/owner thread, synchronous bounded model operations, no startup side effects, resource release by object destruction; no background tasks to cancel. Engine capabilities: none; synthetic fixtures only. Failure: invalid, stale or mismatched events rejected without mutation; cap explicit. Disable/remove by omitting prototype target; production bootstrap does not reference it. Tests: `tests/test_workflow.cpp`, CTest `P0_workflow_models`. Compatibility: prototype v1, not serialized or a native ABI; review before integration.
