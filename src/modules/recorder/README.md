# Recorder worker — P0-T18, source-level v1

Public worker.hpp: injected Sink begin/write/finalize/abort on one worker thread; Packet owns bytes, stream, presentation timestamp and duration in 100 ns units relative to a caller-established common origin. Worker starts on construction. Borrowed Sink must outlive Worker, be exclusively used by its worker thread, and implement nonthrowing abort even after partial initialization. One control owner calls stop/cancel/join; producers may offer concurrently. Producers must stop before Worker destruction. No native hooks, clock mapping, capture ownership ledger integration or production Media Foundation sink adapter. The opt-in synthetic media probe now exercises a real isolated worker sink (verified on Windows); no game capture.

Queue limits: 1..128 slots, 1..16 MiB per packet including vector capacity, at most 64 MiB queued payload capacity plus one in-flight packet and container overhead. Offer takes an rvalue, moves only on acceptance, uses short mutex and may allocate; not a hard real-time or wait-free API. No encoder or I/O under queue lock. Per-stream nonoverlapping timestamps; gaps permitted, not silently retimed. Full queue drops incoming packet, advances stream watermark and counts the drop; invalid packets rejected separately. Stats are aggregate, not a proof of full capture; producer must handle closed/exception outcomes, gaps and drops. No synthetic missing-frame insertion. No guarantee of cross-stream arrival ordering beyond FIFO; downstream mux adapter must validate timestamp requirements.

Stop drains accepted queue and finalizes; cancel discards queued packets, allows in-flight call to return, aborts instead of finalizing. Cancellation cannot interrupt a blocking sink call or an already-started finalization. Failure aborts and counts accepted but unwritten packets. Finalized state means only backend finalization returned, not complete evidence. Owner-thread wait_ready/join/destructor may block; never call them in loader lock, hook, callback or game frame. One-use worker; no restart. Need backend timeouts/cancellation, device failure and sustained load tests before real capture. No files/config owned by worker. Depends on standard C++17/thread only; optional and unregistered in bootstrap. Tests test_recorder_worker.cpp: deterministic promise-gated overflow/drain, cancellation, failure, invalid ordering and bounds. Removable independently.

T18 actual Windows synthetic adapter test: run 45777095746 job 139763270864; 24 packets finalized without observed queue drops, H.264/AAC decoded successfully. See docs/architecture/RECORDING_FEASIBILITY.md.
