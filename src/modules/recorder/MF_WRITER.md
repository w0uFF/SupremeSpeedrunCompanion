## Module boundary

adapters/windows/mf_writer.hpp owns the common COM and MF startup/shutdown, media types, stream configuration, sample submission and resource release extracted from the original fixture. Writer implements the existing Sink interface; Worker alone controls its lifecycle. The fixture facade retains VideoSpec, low/HD presets, fps/period, PCM constants, Com/Foundation/check/type/audio_type/open_writer helpers and AsyncSink constructor and fault observation methods. AsyncSink now delegates begin/write/finalize/abort to Writer; failure injection remains outside the common writer. Source comparison retains the original 39 matched API-call/diagnostic expressions in order (nominal_fps substituted for fixed fps); sample submission body is verbatim, release order writer/MF/COM unchanged, exact original fault injection expressions retained. COM and Foundation guards are noncopyable. Fixture profile remains 160x96 or 1280x720 NV12/H264 at nominal 25fps and fixed PCM 48kHz stereo 16-bit / AAC output. No changed stdout in probe consumers. Compatibility is intended, not runtime-established for this candidate.

public/mf_packet.hpp holds portable copied destination and packet checks used by Writer. Destination owns a private path string, rejects empty/embedded-NUL strings, and is not a filesystem reservation, path-security check, global output identity or archive claim. Existing Worker bounds/stream monotonicity remain authoritative. Packet size, audio enabled flag, stream enum, positive duration and signed-64-bit timestamp end are checked before platform calls. No PTS/duration conversion, interpolation or audio-source acquisition. Fixed 7680-byte PCM packet profile is preserved for fixtures only. Additional invalid stream/zero duration rejection is consistent with existing Worker admission. Fixture paths that are null/empty now reject at construction rather than reach MF; valid existing callers inspected.

Production integration seam: OutputLease::make_writer(format) may return mf::make_video_writer(resolved_reserved_private_path, format). The factory validates existing VideoFormat, copies path and format and explicitly disables audio. OwnedVideoSink continues to own OutputIdentity, reserve the lease, observe budget and seal/incomplete state. The writer does not allocate tokens, reserve files, create directories, persist metadata or validate path confinement. No concrete OutputProvider is introduced; atomic no-overwrite, real quota, durable recovery and path safety remain required. Direct calls to Writer's raw fixture-oriented constructor and low-level helpers require validated configuration and a private destination; they are not a replacement for the lease. No automatic deletion. Writer is created before Worker lifecycle, all COM/MF calls on Worker thread, abort releases partially initialized resources, finalize releases after successful Finalize, worker must join before wrapper destruction. A blocked MF call remains noninterruptible by this code. No native hook, new capture experiment, recording activation, actual audio support, provenance or eligibility change.
