# B-REC-03 — Recorded video overlays (offline candidate)

## Module boundary
Optional recorded-frame projection, not native HUD, observation producer, timer or detector. public/recorded_overlay.hpp owns immutable-by-copy history, bounded canvas, injected renderer, bitmap implementation and composer. public/overlay_frame_source.hpp decorates unchanged FrameSource in MediaFactory on its capture lane. WorkerBackend, Worker, Sink, TimedFrame, pixel conversion, shared observations and Session unchanged. No duplicate engine event schema, raw keyboard hook, game mutation, native activation, filesystem output, service or proof claim.

## Observations
One History per nonzero instance capture ID; decorator rejects mismatched capture. Publish full value snapshots with strictly increasing nonzero sequence and exact 100 ns timestamp from same epoch as TimedFrame.time. Fixed 256-entry ring, short mutex, no dynamic allocation on publish; evicted history missing. Select latest retained sample at or before frame time, never future. Missing shows OBS UNKNOWN; age exceeding inclusive max_age shows OBS STALE without old values. Default 250 ms, configurable positive up to 1 s, provisional presentation freshness only. Producer must publish replacement at each attempt transition and capability loss, coalesce equal-time updates. No field merging across samples/attempts, interpolation, extrapolation or retrospective proof. A owns real epoch correlation, reliable event ordering and delivery; stale labels cannot detect a missing transition within freshness window.

Snapshot: supplied Origin, paired session/attempt IDs or both absent, optional independent RTA/IGT milliseconds, up to eight mapped game actions (unique uppercase alphanumeric/hyphen labels <=8 chars; no physical keys; digital 0/1 or signed analog permille -1000..1000, optional value unknown), recording/integrity presentation enums. Unavailable origin or absent attempt cannot carry numeric timers/actions. No clocks or detector implemented. No known anomaly is not verified clean; native label is supplied origin, not authenticated provenance. IGT not established as actual official displayed time. Replay/import labels and producers pending; do not mislabel replay as live. No persistent observation history or disclosure.

## Composition
BitmapRenderer uses dependency-free 5x7 grayscale glyphs: origin, RTA/IGT seconds with three millisecond digits, IDs, recording/integrity and inputs. Unknown explicit, stale/missing distinct; line must fit or omitted with CLIPPED marker where possible. Canvas restricts pixel writes. Layout disabled by default, panel 480x128 at even x8/y8, configurable even dimensions <=640x160 and even anchor <=4096. Prototype opaque black panel; legibility after encoding, aesthetic scaling/transparency and placement avoiding menu/result proof remain to be validated.

Composer validates packed NV12 (even dimensions <=4096, <=16 MiB), creates bounded BGRA patch, reuses bgra_to_nv12, copies source only when rendering enabled and successful, replaces Y/UV only within even rectangle. Pixels outside rectangle and absolute timestamp unchanged; no retiming, interpolation, rescale or source mutation. Disabled calls no renderer. Clipped preview can contain partial panel but not partial numeric line. Enabled OverlayFrameSource rejects clipping/failure/invalid frame via ReadKind::error, causing incomplete through unchanged backend/orchestrator; no silent omission. Missing/stale labels are valid rendered output, not complete observation coverage. Explicitly disabled passes original frames unchanged. No separate raw video persisted.

Factory supplies unique source/renderer, shared const History (owner retains mutable publish ref); renderer stays on capture lane, not game owner or encoder Worker. Read then composition then unchanged lookahead/Worker/Sink. Idle/end/error passed unchanged. Extra one NV12 frame <=16 MiB plus BGRA patch <=409600 bytes and NV12 patch <=153600 bytes; existing buffers/queues separate. Allocation/renderer exceptions fail closed. Polling budget plus composition overhead unmeasured; hung renderer may block lane like prior source/codec, no hard realtime guarantee. Generic source_error does not distinguish overlay failure in persisted report; later UI/recovery work. No physical capture, MF or native input validation.

## B-REC-03b — Identity and integrity presentation review (A-0007)

This successor extracts the existing presentation model into public/overlay_observation.hpp (included by recorded_overlay.hpp) and adds optional Snapshot::validated_loaded_track using the existing categories::Track enum. No engine or shared schema edits. The catalog contains nine competitive track/difficulty pairs; the two multi-track categories are not individual track identities. The existing reference classifier describes 36 weather-specific competitive resource configurations, not loaded geometry. Neither a menu selection, a planned category, Session event acceptance alone, resource path classification nor consistency of submission claims supplies validated_loaded_track. Only a producer with independently validated loaded identity bound to the same capture/session/attempt and clock may populate it; otherwise leave absent. No such native producer is available today. Synthetic inputs retain their SYNTHETIC label. Invalid enum, identity without paired attempt/session, or unavailable origin with a track is rejected. Bitmap prints combined canonical catalog label in uppercase (e.g. TRACK: ALPINE - EASY), or TRACK: UNKNOWN. No duplicative difficulty table. A producer must publish explicit unavailable replacement after validation loss; rejected malformed publications do not replace previous valid observations. Freshness is not a substitute for producer reliability.

History::publish_tick(samples,size) is an atomic ordered group of 1..16 full snapshots at one exact 100ns tick; sequence strictly increasing within/across groups, ticks strictly increasing between groups, one capture identity. No partial admission. Store only the final full value copy plus tie/quarantine metadata in the existing fixed 256-entry ring; no field inheritance, event detector or event-history guarantee. Existing publish(s) means a complete one-sample group. A tied group at exactly the frame tick yields OBS AMBIGUOUS (frame has no sequence ordering); a strictly later frame sees final state subject to freshness. A valid late extension of the most recent tick with a newer sequence is rejected, advances the sequence watermark and quarantines that interval until a new complete tick. Older timestamps and duplicate sequences rejected; historical data not revised. Producer must submit complete groups in order before relevant composition, including same-tick transitions/capability loss; no retroactive repair of frames already encoded and no claim about unreported events or earlier out-of-order updates. Single completed tick equality retains previous semantics. The 16-group limit and 256 distinct tick bound are provisional. Eviction yields missing. Expired groups yield stale even if tied/quarantined.

Selection copies downgrade supplied no_known_anomaly to insufficient if track, attempt, origin, either timer, mapped action values or usable recording state absent; stored sample unchanged. Other supplied integrity statuses are never upgraded or changed by this guard. This is a conservative presentation condition, not a calibrated coverage or verification rule; it does not establish clean play even when all fields present. Missing/stale/ambiguous renders OBS UNKNOWN/STALE/AMBIGUOUS, TRACK: UNKNOWN and CHECK UNKNOWN, never old values or no-known-anomaly. Bitmap defensively rejects inconsistent direct selection payloads. Producer remains responsible for sticky confirmed violations, accepted event semantics, source validity and actual check coverage; no independent detector or durable finding history here. Existing disabled/clipped/failure behavior, same NV12 conversion, frame timestamp and outside-patch pixels unchanged. The extra track line fits all eight actions in default 128 px panel; smaller layouts can fail closed via existing clipped result. Actual encoded legibility/placement/latency and native identity remain pending. DEMO-TRACK-01 and existing competition rules unchanged.
