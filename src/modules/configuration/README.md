# Configuration module — schema 1, P0-T21

Source-level C++17 typed settings and controller in public/settings.hpp. Separate from Python offline reference, intended for future native consumers. No actual JSON parser, launcher adapter, persistence implementation or bootstrap registration. Store and PathPolicy injected by reference, must outlive Controller; calls are synchronous on one owner thread outside gameplay callbacks. Store must provide coherent load and transactional save or throw on failure; mock only. Nonempty UTF-16 package path requires injected policy; 240 UTF-16 code unit bound, no default filesystem adapter. Python prototype has a lexical path check; cross-language serialization/Unicode boundary requires explicit conformance tests when native adapter added. Source enum values are not persisted ordinals; serialize stable textual settings names. Empty path represents future application-managed default. Settings validation covers enum ranges, FPS, bitrate, opacity, free disk preference and duplicate assigned hotkeys. Book checks schema, count, ASCII profile names, case-insensitive uniqueness and exact active selection. Controller resolves selected profile or whole launcher override, can create separate session snapshot and replace existing persistent profile via injected Store. Snapshot returned by value; caller owns const copy for active attempt, not an immutable type or official run binding. No create/rename/delete in C++ port yet; Python prototype provides those. No encoder, overlay, timer, capture, hotkey, retention deletion or network effects. Test tests/test_configuration_port.cpp; fake store and path policy only. Removable independently.

T22 native adapters: restricted schema-1 ASCII JSON codec (objects, bools, unsigned integer settings and escaped UTF-16 strings; no arbitrary JSON), canonical profile roundtrip tests and Windows FileStore in a caller-owned existing private directory. Lexical path validation is separate from existing fixed-drive plain-directory/free-space resolution. No directory creation by profile store, no concurrent writer or adversarial path guarantee, no game connection. Native actual launcher mods.json parser still absent. CI pending at preparation.

T23: infrastructure/launcher_json.hpp bounded read-only PR66 JSON projection; windows_launcher_state.hpp and shared plain-file reader implement explicit directory-based file ingestion. tools/configuration/preview.cpp standalone native consumer, no game bootstrap. public/attempt_settings.hpp owns immutable const Snapshot. Actual upstream serializer/preview conformance passed; native profile persistence and Python exchange tested. GUI and CLI separate. Current bounds, limitations and precedence in SSC_CONFIGURATION.md; no game/recorder dependency.
