# Run library — P0-T18 source-level port v1

Public repository.hpp: immutable Record (run/category/profile/event-semantics IDs, manifest SHA-256, origin/status, nullable IGT ms/RTA ns), separate Annotation, Repository insert/find/recent/annotate. Backend must return inserted/identical/conflict based on immutable content, not overwrite existing ID; missing find is null, storage errors propagate. Caller validates schema/provenance, handles errors and bounded recent query. Comparable helper filters local finished records by exact category/profile/semantics and method-specific non-null time; not an eligibility check, does not verify identities or evidence. No production implementation, persistence, synchronization, schema migration or UI. Borrowed adapter owner must schedule I/O off game thread. Existing Python SQLite reference store is not wired to this port. Standard C++17 only; removable, no native capability. Test test_run_repository.cpp exercises comparison semantics, including zero vs unknown, imported/synthetic exclusion. Future adapter contract tests needed for duplicate and transaction behavior.
