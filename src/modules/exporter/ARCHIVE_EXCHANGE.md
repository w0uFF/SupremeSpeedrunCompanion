Use existing run_library::Repository const find, Record, identical and record_validation unchanged. public/archive_exchange.hpp under exporter provides Controller and a feature-local Port covering selected source, managed archive and destination observations plus guarded admit_import and publish_exact operations. Import and re-export share the same checked archive/projection and exclusive-publication semantics. No new archive schema, database, ZIP parser, hash implementation, archive-format migration or shared API. No dependence on recorder or native engine. Existing attempt_binding.hpp is a redacted settings snapshot, not an archive/source authority. Existing submission drafts, track-claim consistency, hosted submission and synthetic journal/retry remain separate; none establishes eligibility. No new networking, upload, deletion or retention policy. No persisted controller state, owned threads, queues or startup side effects. Optional port may be absent, yielding unavailable; history/recording remain independent.

Caller retains an explicit copied selection/intent and dispatches on the serialized I/O owner thread; repository and port outlive controller. Both refer to the same bound index and quiescent private managed storage. Adapter owns expiring, nonreused selection tokens: exactly 32 lowercase hex, scoped to one explicitly chosen source file or export destination; not a filesystem path, run ID, authorization or persisted locator. No arbitrary path from manifest or row, no automatic scan or token discovery. User must explicitly confirm import/export, including local file destination and disclosure. Token acquisition, binding to safe paths/handles and expiry are adapter responsibilities NOT implemented. No new job scheduler, cancellation, physical quota or hard deadline; bounded inputs/one operation per call, hashing/file copy can block on owner I/O thread and must never run on game or rendering callbacks.

## Verified projection and limits

Existing tools/evidence_archive.py verify(include_manifest=True) validates stored classic ZIP/manifest, member hashes, schema2 metadata and optional redacted attempt-settings evidence. index_archive.checked/project restricts schema2 to known attempt status, maps ordinary imports to imported (regardless of manifest-declared origin), preserves synthetic only via explicit fixture mode, category unclassified, exact reserved profile SHA256 of ASCII SSC:unclassified-index-v1 (08b64d85d27f15b13d4baf59bd2601cbac76748d6f5109d660e7188a6564d35e), validated event semantics or unknown, caller-supplied nullable elapsed values. This is not an approved competition profile. Schema1, unsupported status, local admission, synthetic-fixture creation/reconciliation, new local packaging and actual gameplay are not supported by this controller.

Verified is an adapter-produced observation: exact Record projection from checked/project, independent SHA256 of entire ZIP container (not manifest digest), physical byte count 22..existing MAX_TOTAL+MAX_MANIFEST+CHUNK (1 GiB+64 KiB+1 MiB). Reuse existing verifier/stream_digest, not new parsing/hash code. Controller validates shapes, origin and exact unclassified projection namespace, compares all record fields plus container digest and length. A caller can fabricate a Verified value; it authorizes no action without a matching fresh independently verified port observation. This is consistency checking under trusted adapter contract, not authentication. The extra whole-ZIP digest is transient, never changes DB/schema. It distinguishes byte-identical copies from archives with identical manifest but differing ZIP bytes. Deliberately conservative: even ordinary import retry/dedup requires same whole ZIP, unlike existing index_archive.admit's manifest-only dedup; same manifest/different container requires review/conflict in this feature. Not a new competition rule.

## Read and command flows

preview_import verifies one selected external file in ordinary imported projection only; preview_export checks the actual indexed nonlocal record then reads its managed archive. Read-only preview does not mutate. Execute re-reads source and compares full expected projection, physical digest/size; refuses stale/missing/unavailable/invalid observations. Export additionally requires selected exact current Record and finalized managed source with no pending alias. Mutable annotations are never consulted or added to an archive; export copies original bytes, no reconstruction/repack or metadata edits. Existing archive may contain arbitrary diagnostic payloads or personal information; this does not sanitize or certify privacy. Do not claim that all existing payloads are safe or free of private data.

SlotState: absent, verified pending, finalized, proven same-file pending alias, review, unavailable. Slots with invalid enum or inconsistent payload shape become review. Adapter must map archive_status/archive file facts, including separate pending conflict, corrupt/unsafe/identity mismatch to review; missing vs verifier/index unavailable distinct. Alias must mean actual same-file link, not identical digest copies. Recheck exact expected current state inside every effect operation. No automatic recovery from invalid pending/conflicting targets.

Import: require current source verified in ordinary imported projection; read actual index record. Missing index permits absent slot, exact pending, exact finalized (unindexed) or exact alias. Identical existing record plus exact final yields unchanged; exact alias may be explicitly reconciled via existing admission; missing archive or pending with existing row yields review (orphan/inconsistent). Any other record, including local/synthetic, conflicts. No controller insert; adapter uses existing nonlocal admit and exact bound comparison/index insertion. Re-read managed final and actual index after at most one admit call, require completed acknowledgement, exact verified container and full identical indexed record. Explicit retry after interruption follows fresh checks; no automatic write on errors.

Export: current indexed imported or synthetic exact Record and verified finalized managed archive must match the selected preview. Destination absent or exact verified pending permits one guarded publish_exact; exact final is unchanged (no write); different final/pending/alias bytes conflict; even matching export alias requires explicit external review, no cleanup by this controller. Never overwrite or modify source. Post-read destination, managed source and actual index: completed only if acknowledgement completed and all match. No unverified reconstruction from metadata or arbitrary file export.

Result carries code, attempted flag, optional operation acknowledgement (absent on exception) and observed Slot (preflight relevant source/target or post-attempt target). Any non-completed acknowledgement, exception, missing/invalid/mismatched postcondition yields operation_uncertain; may have partially succeeded, even if post-read matches. Acknowledgement conflict/review/unavailable is retained. No retry, rollback, delete or promotion by controller. Caller refreshes/explicitly retries. No fabricated success, exact record/ZIP matching is not proof of video playback, complete submission, honest play or durable commit. Read/write are not an atomic cross-store transaction, cannot prevent hostile concurrent mutation or ABA. Source/destination/path guard enforcement and source preservation depend on actual adapter; fake tests do not prove filesystem properties.
