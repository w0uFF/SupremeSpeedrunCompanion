# Extension feasibility mock v1 (P0)
Purpose: offline C/C++ interoperability and lifecycle negotiation; not a supported loader API, does not discover or load DLLs. Public `contract.h`, implementation `mock.cpp`, test `tests/test_extension.c`. Requires only standard C99/C++17; no feature deps or engine capabilities. No config/files or native resources. Caller owns the API table, initializes context pointer to null, passes valid accessible objects of exact declared sizes; mock owns allocation and frees on close. Calls are serialized on one owner thread; not thread-safe, no callbacks/worker. The host must not copy or reuse a freed context. Open fails without changing context for unknown phase, disabled state, wrong size/version or active handle. Null/double close rejected. No exceptions cross boundary; allocation failure is BAD_STATE in this prototype. ABI uses cdecl on Windows; struct size includes platform pointer layout, exact size required, no cross-process serialization. Native x86 ABI, Rust `repr(C)`, loading/unloading and loader lock NOT_RUN. `SSR_PHASE_OFFLINE_SAFE` is synthetic only. A real ABI needs explicit host verification, separate activation and shutdown contracts; no game object pointers. Removable mock target, no changes to existing observation schema or bootstrap.
